Suivi Ruches est une application de suivi apicole conçue pour les apiculteurs amateurs et professionnels pratiquant l'apiculture douce.

## Fonctionnalités

- **Gestion des ruches** : Suivi de plusieurs ruches avec leur état, reine, cadres et comptage des varroas
- **Visualisation des cadres** : Représentation visuelle de chaque cadre avec type et contenu
- **Journal d'interventions** : Enregistrement détaillé de toutes les opérations (observation, traitement, récolte, etc.)
- **Template d'observation guidée** : Checklist structurée pour ne rien oublier
- **Dictée vocale** : Enregistrement mains libres avec reconnaissance vocale (français)
- **Photos** : Plusieurs photos par intervention avec vue plein écran
- **Inventaire** : Suivi des cadres, équipements, nourriture (sirop/candy), et fournitures
- **Dr. Abeille IA** : Assistant apicole avec IA (nécessite une clé API Anthropic)
- **Analyse Flore & Faune** : Identification des plantes mellifères et insectes (avec analyse photo)
- **Calendrier mensuel** : Tâches et risques saisonniers
- **Alertes automatiques** : Risque d'essaimage, reine absente, surcharge de varroas

## Technologie

- HTML5/CSS/JavaScript (pas d'outils de build requis)
- Serveur Node.js + Express
- localStorage pour persistence offline
- Intégration optionnelle de l'API Claude (Anthropic) pour les fonctionnalités IA
