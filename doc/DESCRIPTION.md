Suivi Ruches is a beekeeping monitoring application designed for hobbyist and professional beekeepers practicing gentle beekeeping ("apiculture douce").

## Features

- **Hive management**: Track multiple hives with their state, queen, frames, and varroa counts
- **Frame visualization**: Visual representation of each frame with type and content
- **Intervention journal**: Detailed log of all hive operations (observation, treatment, harvest, etc.)
- **Guided observation template**: Structured checklist to never forget important observations
- **Voice dictation**: Record observations hands-free using speech-to-text (French)
- **Photo support**: Multiple photos per intervention with full-screen viewing
- **Inventory management**: Track frames, equipment, food (syrup/candy), and supplies
- **Dr. Abeille AI**: AI-powered beekeeping assistant (requires Anthropic API key)
- **Flora & Fauna analysis**: Identify melliferous plants and insects (with photo analysis)
- **Monthly calendar**: Tasks and risks reminders by season
- **Automated alerts**: Swarming risk, missing queen, varroa overload warnings

## Technology

- HTML5/CSS/JavaScript (no build tools required)
- Node.js + Express server
- localStorage for offline-capable data persistence
- Optional Anthropic Claude API integration for AI features
